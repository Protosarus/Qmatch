# QMatch Quantum-Inspired Experimental Layer — Boundary v1

**Phase:** P2C-2A-0  
**Status:** Experimental offline research only

---

## Hard boundaries

1. Canonical IQ **item generation** remains classical and explainable.
2. Canonical IQ **scoring** remains classical (keyed MCQ / trait scoring contracts).
3. The quantum-inspired model is **not** used for answer correctness.
4. It is **not** used for IQ scoring.
5. It is **not** used for question selection.
6. It is **not** used in production matching in this program phase.
7. It may later be evaluated **offline** against Core Method v2 outputs.
8. No consumer-facing “quantum IQ/matching” claim may be made without empirical evidence.

## Schema implication

`iq_item_schema_v1` **forbids** quantum score / amplitude fields and fake psychometric parameters presented as calibrated truth.
