# Frequency Dimension Contract v1

**Status:** provisional measurement contract (P2A-2D-1)  
**Module:** Frequency (product-facing name may remain “Frequency”)  
**Internal meaning:** observable interaction preferences, relational rhythm, communication cadence, social-energy preferences, disclosure timing, and routine-versus-novelty preferences  
**Calibration:** uncalibrated  
**Does not claim:** clinical validity, mystical frequency, moral worth, IQ, EQ ability, or psychiatric traits  

---

## Global rules

| Rule | Statement |
|---|---|
| Pole neutrality | Both higher and lower poles may be compatible with healthy functioning |
| No global better | No direction is globally better, more mature, or more “compatible” |
| Compatibility | May depend on similarity, complementarity, mutual expectations, and context — not on this contract alone |
| Missing data | Unanswered / void items contribute **no** evidence; never invent `0`, `0.5`, or `0.42` |
| EQ separation | Frequency items must never write deltas to EQ dimensions |
| Alias caution | Legacy `emotionalOpenness` maps conceptually only to `disclosure_pace`, never to EQ `emotional_openness` |

## 1. `depth_preference`

| Field | Content |
|---|---|
| Canonical ID | `depth_preference` |
| Definition | Preference for the degree of reflection, complexity, personal meaning, and substantive exploration desired in interaction |
| Higher pole | Greater preference for reflective / substantive conversation; exploring meanings, motives, ideas, or experiences |
| Lower pole | Greater preference for lighter, practical, activity-based, or present-focused interaction |
| Observable behaviors | Topic choices; how long someone stays on reflective threads; preference for “how/why” vs logistics |
| Not safe to infer | Intelligence, maturity, communication skill, emotional superiority, being “more interesting” |
| Common confusions | Verbal ability; IQ verbal_reasoning; EQ emotional_openness / empathy |
| Relationship to EQ | Distinct from EQ empathy / emotional_openness (those concern affective weighing / disclosure willingness as EQ constructs) |
| Compatibility relevance | Pace of meaning-making in shared talk |
| Prohibited moral readings | Deep = better; light = shallow/defective |
| Missing-data behavior | Omit from published Frequency scores when insufficient evidence |
| Calibration status | Uncalibrated provisional |

## 2. `social_energy`

| Field | Content |
|---|---|
| Canonical ID | `social_energy` |
| Definition | Preferred amount, intensity, and continuity of social interaction, plus desired recovery space afterward |
| Higher pole | Comfort with more frequent / sustained engagement; shared activity and interpersonal stimulation |
| Lower pole | Preference for lower-intensity contact, more recovery time, smaller settings, selective engagement |
| Observable behaviors | Outing choices; group vs solo preference; post-social recovery requests |
| Not safe to infer | Popularity, social skill, empathy, confidence, clinical introversion/extraversion |
| Common confusions | Social skill; EQ social_awareness; popularity |
| Relationship to EQ | Not EQ social_awareness (reading cues) and not EQ empathy |
| Compatibility relevance | Shared activity load and recovery expectations |
| Prohibited moral readings | High energy = healthier / more attractive; low energy = antisocial |
| Missing-data behavior | Omit when insufficient |
| Calibration status | Uncalibrated provisional |

## 3. `spontaneity`

| Field | Content |
|---|---|
| Canonical ID | `spontaneity` |
| Definition | Preference for unplanned choices, flexible changes, improvisation, and novelty in interaction / shared activities |
| Higher pole | Comfort with last-minute plans; changing direction; improvisation and novelty |
| Lower pole | Preference for preparation, advance notice, predictable arrangements, deliberate decisions |
| Observable behaviors | Reaction to plan changes; desire for advance scheduling; improvisation comfort |
| Not safe to infer | Impulsivity, irresponsibility, creativity, risk-taking ability, emotional instability |
| Common confusions | Impulsivity; EQ emotion_regulation; “flakiness” |
| Relationship to EQ | Not emotion_regulation and not conflict_approach |
| Compatibility relevance | Planning flexibility expectations |
| Prohibited moral readings | Spontaneous = fun/good; planned = rigid/bad (or reverse) |
| Missing-data behavior | Omit when insufficient |
| Calibration status | Uncalibrated provisional |

## 5. `disclosure_pace`

| Field | Content |
|---|---|
| Canonical ID | `disclosure_pace` |
| Definition | Preferred speed, sequencing, conditions, and depth progression for sharing personal or emotionally significant information |
| Higher pole (faster) | Personal / emotional topics opened earlier or more quickly |
| Lower pole (slower) | Trust and context develop before personal disclosure; gradual sharing |
| Observable behaviors | When personal topics open; conditions asked before sharing |
| Not safe to infer | EQ emotional_openness, honesty, secrecy, trustworthiness, trauma, intimacy capacity, general willingness to communicate |
| Common confusions | **EQ `emotional_openness`**; honesty; trust |
| Relationship to EQ | **Must never map to or write EQ `emotional_openness`** |
| Legacy alias | Legacy Frequency `emotionalOpenness` → conceptual source for `disclosure_pace` only |
| Compatibility relevance | Mutual expectations about how quickly personal material appears |
| Prohibited moral readings | Fast = honest/intimate; slow = secretive/cold |
| Missing-data behavior | Omit when insufficient |
| Calibration status | Uncalibrated provisional |

## 6. `communication_pace`

| Field | Content |
|---|---|
| Canonical ID | `communication_pace` |
| Definition | Preferred cadence, timing, response rhythm, continuity, and spacing of communication |
| Higher pole | Preference for more frequent replies, shorter gaps, more continuous flow |
| Lower pole | Comfort with longer gaps, less frequent contact, asynchronous rhythm |
| Observable behaviors | Reply timing preferences; comfort with silence gaps; async vs continuous chat |
| Not safe to infer | Communication skill, interest, affection, reliability, assertiveness, attachment style, respect |
| Common confusions | **EQ assertiveness**; interest/affection; attachment |
| Relationship to EQ | Not assertiveness; not repair_orientation |
| Compatibility relevance | Messaging rhythm expectations |
| Prohibited moral readings | Fast replies = caring; slow replies = disinterest |
| Missing-data behavior | Omit when insufficient |
| Calibration status | Uncalibrated provisional |

## Explicit separations (summary)

| Frequency dim | Must not be treated as |
|---|---|
| `disclosure_pace` | EQ `emotional_openness` |
| `communication_pace` | EQ `assertiveness` / affection / interest |
| `social_energy` | Social skill / popularity |
| `spontaneity` | Impulsivity / irresponsibility |
| `stability` | Emotional stability / loyalty |
| `depth_preference` | Intelligence / maturity |
